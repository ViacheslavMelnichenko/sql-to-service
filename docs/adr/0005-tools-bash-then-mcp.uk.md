# 0005 — Гейт-тули: Bash-скрипти зараз, MCP як stretch

- **Статус:** Accepted
- **Дата:** 2026-08-07
- **Ухвалив:** Viacheslav Melnichenko

## Контекст

Детерміновані судження — захопити golden, білд, запустити юніт-тести, запустити
диференціал — це тули, які викликають агенти. Є два природні способи експонувати їх
агенту Claude Code: як CLI-скрипти через Bash-тул, або як типовані тули від власного
MCP-сервера. Це компроміс розмір-vs-сигнал для артефакту розміру S.

## Драйвери рішення

- Тримати бюджет розміру S; не додавати підсистему, яка не потрібна артефакту для
  доведення тези.
- Гейт має бути оглядним для рев'ювера *і* викликним хуком *і* викликним агентом —
  ідеально той самий артефакт для всіх трьох.
- Лишити чіткий чесний шлях показати MCP-компетенцію без роздування обсягу зараз.

## Розглянуті опції

1. **MCP-сервер з самого початку.** Типований контракт (`run_procedure`,
   `diff_against_golden`), сильніший сигнал. Відхилено зараз — цілий сервер будувати
   й обслуговувати, і він роздуває артефакт за межі S ще до того, як стоїть ядро.
2. **Тільки Bash-скрипти, назавжди.** Просто й чесно, але лишає MCP-компетенцію
   непоказаною.
3. **Bash зараз, MCP як позначений stretch.** Обрано.

## Рішення

Експонувати гейт-тули як **Bash-скрипти** під `gates/` (`build.sh`, `unit.sh`,
`differential.sh`, `verify.sh`, `mutation-check.sh`). Один скрипт:

- **викликний агентом** через Bash-тул,
- **викликний хуком** (`PostToolUse`, `Stop`) тим самим викликом,
- **читабельний рев'ювером** як звичайний shell — у гейта немає прихованої магії.

**MCP — запланований stretch, не частина ядра.** Щойно харнес і гейт стоять, а
бюджет дозволяє, один тул (`diff_against_golden`) переробляється на малий
MCP-сервер як демонстрація підходу типованого контракту — чітко позначений як
опціональний і додатковий, ніколи не блокує ядро.

## Наслідки

- **Плюс:** менше рухомих частин; гейт — той самий shell-артефакт для агента, хука
  й людини. `verify.sh` відтворює опубліковану таблицю без викликів моделі.
- **Плюс:** чесний MCP-шлях існує без оплати наперед.
- **Ціна:** Bash-скрипт — слабший сигнал «типований контракт», ніж MCP; прийнято —
  stretch це закриває, якщо бюджет лишається.
- **Ціна:** дбати про переносимість shell (CI і рев'ювер ганяють Linux-контейнери;
  скрипти цілять POSIX sh).
