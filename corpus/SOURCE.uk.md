# Джерело корпусу

Корпус — публічна, MIT-ліцензована семпл-БД **WideWorldImporters** від Microsoft.
Використання відомого публічного семплу навмисне: рев'ювер упізнає схему з
першого погляду, може звірити наші витяги процедур з upstream-джерелом і відтворити
все без жодних приватних даних.

## Пін

| Поле | Значення |
| --- | --- |
| БД | WideWorldImporters — бекап **Standard** edition |
| Файл | `WideWorldImporters-Standard.bak` |
| Upstream | Microsoft `sql-server-samples` GitHub release `wide-world-importers-v1.0` |
| Ліцензія | MIT |
| SHA-256 | `<пінується під час restore — див. corpus/restore.sh>` |

> **Чому Standard, не Full.** Бекап **Full** використовує in-memory OLTP
> filegroups і columnstore-фічі, які не відновлюються в Linux-контейнері SQL
> Server — саме те середовище, яке `docker compose` дає рев'юверу. Бекап
> **Standard** відновлюється чисто на `mcr.microsoft.com/mssql/server` і несе ту
> саму схему й ті самі збережені процедури, які ми конвертуємо. Цей вибір і тримає
> «відтворити з чистого клону» чесним.

## Що ми беремо

Лише **збережені процедури** у двох схемах (див. `SELECTION.md`) і **зріз даних,
що покриває гілки**, потрібний для їх виконання (див.
`docs/adr/0002-dataset-sizing.md`). Ми **не** комічимо `.bak` — його завантажує і
SHA-перевіряє `corpus/restore.sh`. Комічимо лише:

- витягнутий текст процедур (`corpus/procs/*.sql`),
- seed, який виводимо (`corpus/seed/*`),
- golden-вивід, який захоплюємо (`corpus/golden/*.json`).

## Цілісність

`corpus/restore.sh` завантажує пінований `.bak`, звіряє його SHA-256 із записаним
вище значенням і **голосно падає** на розбіжності — змінений upstream-файл це
supply-chain подія, а не щось, що тихо відновлюють. SHA заповнюється раз, з
реального завантаженого артефакту, і ніколи не редагується під нове завантаження
без нотатки в `CHANGELOG.md`.

## Введена специфіка (перекривай дешево)

- **Standard замість Full** — обрано для сумісності відновлення в Linux-контейнері;
  це реальне обмеження, не преференція.
- Точний release-тег `wide-world-importers-v1.0` і SHA — плейсхолдери, поки
  `restore.sh` не запише їх з реального завантаження.
